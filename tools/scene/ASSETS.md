# External assets used by the gorge scenes

All from Poly Haven (https://polyhaven.com), licence CC0 1.0 (https://polyhaven.com/license). Downloaded at 2k via https://api.polyhaven.com/files/<id> by `fetch_assets.py`.
Everything else (gorge terrain, gneiss shader, water, waterfall, bridge, trees, sky) is procedural, made in the scripts.
