# Project log tags

The vocabulary for the `tags` field of log entries. Add a tag when an entry needs one, with a
one-line meaning; reuse an existing tag whenever it fits.

- `timer-ux`: how the timer looks and behaves for the user (presets, controls, flow)
- `scenes`: the visual scenes, renders and clips, and how they play
- `audio`: bells, ambient sound, playback while the screen is off
- `pwa`: installation, updates, service worker, background and screen-off behaviour
- `qa`: test sessions and checks on real devices
- `infra`: build, toolchain, hosting, render setup, repo conventions
